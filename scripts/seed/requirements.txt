# Seeding-only dependencies (SEED_RUNBOOK.md). Deliberately isolated from
# backend/requirements.txt — the backend app never imports these; only
# scripts/seed/*.py does. Install into scripts/seed/.venv, not the repo-root venv.
#
# System tools required alongside this file (not installable via pip):
#   brew install gdal libpq poppler ollama  # ogr2ogr, psql, pdftotext, local LLM
#   ollama pull qwen2.5:7b-instruct         # English narrative generation model
#
# pdftotext -layout (poppler) is used for BNS/IPC PDF extraction (§2.1) instead
# of a Python PDF library — it preserves the source PDFs' columnar layout far
# more reliably, which the comparison-table and section-body regex parsers
# in extract_bns.py depend on.
#
# Note: GDAL's Python bindings must match the brew-installed GDAL version.
# geopandas pulls in fiona/pyogrio which links against the system GDAL.
